## 6. Items to retain or investigate in implementation

1. **Schedule data source** (F7): decide before building.
2. **Form handling** (F8–F10): recipient emails, spam protection (reCAPTCHA or Turnstile), whether the PDF copy is needed.
3. **Workshop booking path** (F12): keep WooCommerce (headless) or move workshops to Kajabi or a booking link. The client must decide. A static frontend can't reproduce WooCommerce checkout with Xendit.
4. **Kajabi newsletter embed** (F5): Kajabi's embed script injects its own markup and styles, so restyling it may be limited.
5. **Analytics**: replace UA with GA4 or similar. Ask the client for the GA4 property.
6. All Kajabi URLs in [03](03-content-inventory.md) should live in one config file so the client can update program links each year.
